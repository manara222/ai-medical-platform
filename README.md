# 🧠 AI Medical Diagnosis Platform

An AI-powered web application for multi-disease diagnosis using deep learning models.

## 🚀 Features
- Skin disease classification
- Breast cancer detection
- COVID-19 detection
- Eye disease analysis
- Grad-CAM explainability
- Automated report generation

## 🛠 Tech Stack
- Python
- PyTorch
- FastAPI
- Streamlit
- OpenCV
- NumPy
